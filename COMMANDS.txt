==============================================================
TROUBLESHOOTING
==============================================================

If "psql command not found":
- Make sure PostgreSQL 18 is installed
- Add to PATH or use full path: C:\Program Files\PostgreSQL\18\bin\psql

If "database does not exist":
- Create it first: createdb -U postgres blackopspro
- Then: psql -U postgres -d blackopspro -f setup.sql

If "cannot connect to server":
- Make sure PostgreSQL service is running
- On Windows: Services > postgresql-x64-18 > Start
- On Linux: sudo service postgresql start
- On Mac: brew services start postgresql

If "tables already exist":
- That's fine! setup.sql uses "CREATE TABLE IF NOT EXISTS"
- You can run it multiple times safely

If "permission denied":
- Check PostgreSQL user (postgres) has permissions
- Or add current Windows user to PostgreSQL
